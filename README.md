## 🎨 Design System

- **Clean Aesthetic:** Designed with a soft neumorphic palette (`#ecf0f3` base, subtle dual-elevation shadows, and vibrant crimson/sky accents).
- **Responsive Layout:** Optimized from mobile screens (360px) up to ultra-wide displays (4K).
- **Smooth Micro-interactions:** Powered by Framer Motion, Lucide icons, and Tailwind transitions.
- **Fast Performance:** Optimized assets with instant bundle delivery via Vite.

## 💻 Getting Started Locally

### Prerequisites

Ensure you have **Node.js** (v18.x, v20.x, or v24.x) and **npm** installed on your system.

```bash
node -v
npm -v
```

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AnoopkumarA/Renjith_PersonalWebsite.git
   cd Renjith_PersonalWebsite
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

Compile TypeScript and generate an optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
